# 🏥 Hospital Appointment & Live Queue Management System

A production-grade backend system for managing hospital appointments with real-time queue tracking, built using **Spring Boot** and modern backend engineering practices.

---

## 🚀 Features

- 🔐 Secure authentication & role-based access (JWT)
- 👨‍⚕️ Doctor management & scheduling
- 📅 Online appointment booking
- ⏱ Live patient queue system with token management
- 📬 Notification-ready event system
- 🧠 Designed for scalability and real-time updates

---

## 🧰 Tech Stack

| Category | Technology |
|--------|------------|
Backend | Spring Boot |
Security | Spring Security, JWT |
Database | MySQL |
ORM | JPA / Hibernate |
Caching | Redis |
Messaging | Kafka / RabbitMQ |
Real-time | WebSocket |
Deployment | Docker |

---

## 🧱 Architecture

Layered architecture with domain-driven design:

```
Controller → Service → Repository → Database
```

Supports future migration to microservices.

---

## 🧪 Core Capabilities

- JWT Authentication
- Doctor availability scheduling
- Appointment booking & cancellation
- Live queue management with token system
- Clean error handling & validation
